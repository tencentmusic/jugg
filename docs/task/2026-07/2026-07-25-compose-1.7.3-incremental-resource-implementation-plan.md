# Compose Multiplatform 1.7.3 Incremental Resources Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 Jugg 在已有 Gradle 全量构建后，不执行 Gradle 即可增量生成、编译并部署 Compose Multiplatform `1.7.3` 的 Android resources。

**Architecture:** 在现有 `JuggCompiler` 最前面增加独立 `ComposeResourceCompiler`。该阶段按 changed `CompileFile.baseDir` 识别资源单元，由 Jugg 准备 `.cvr` 和非 values assets，隔离调用项目 `compose-gradle-plugin-1.7.3.jar` 生成 Kotlin，再使用现有 `KotlinCompilerInvoker` 编译 generated expect/actual，最终把 class 和 asset 交回现有 D8、minify、overlay 和 deploy 链路。

**Tech Stack:** Kotlin/JVM、JUnit 4、Gradle init script、Compose Multiplatform `1.7.3` internal JVM API、Kotlin `2.1.x` CLI compiler、DOM XML parser、Jugg compiler pipeline。

## Global Constraints

- 设计依据：`docs/task/2026-07/kmp_compose_incremental_compile_support_plan.md`。
- 只支持 Compose Multiplatform `1.7.3` 和 Kotlin `2.1.x`；其他版本必须明确拒绝增量。
- 支持默认 `composeResources`、`customDirectory`、`packageOfResClass`、`publicResClass`。
- 覆盖 `string`、`string-array`、`plurals`、`drawable`、`font`、`files` 以及 language/region/theme/density qualifier。
- 首版只支持新增和修改，不支持删除，不增加 tombstone 或删除缓存。
- 不执行 Compose Gradle generation task，不把 Compose resources 交给 AAPT2。
- 不修改普通 KMP 业务源码编译语义，不增加 KMP source-set 图。
- 不使用 `CompileFile.extraInfo` 传递 Compose common-source 标记；资源归属使用既有 `file/baseDir/module`。
- 不增加持久化 generated cache；每轮只使用 `ICompileContext.tempCompileDir`。
- 代码注释必须使用英文；新增公共类和复杂核心方法必须有介绍性注释。
- 日志只使用 `JuggLogger` 体系：用户输入/兼容失败使用 `warn`，排查细节使用 `debug`，禁止 `error`。
- 严格 TDD：每个 feature task 先增加失败测试，确认失败后才能修改生产代码。
- 测试命令必须带 `--tests`；禁止无过滤执行 `:main:test` 或 `:idea:test`。
- 每个任务只提交本任务文件，commit message 使用英文和仓库规定前缀。
