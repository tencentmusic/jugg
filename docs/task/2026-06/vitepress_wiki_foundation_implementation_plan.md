# VitePress Wiki Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a minimal bilingual VitePress wiki foundation under `docs/wiki`, with English as the default root locale and Chinese under `/zh/`.

**Architecture:** `docs/wiki` is an isolated VitePress docs root. English pages live at the root routes such as `/guide/`; Chinese pages live under `/zh/` with mirrored paths. `docs/wiki/.vitepress/config.mts` owns locale configuration, language-specific nav, and language-specific sidebars.

**Tech Stack:** VitePress `1.6.4`, npm lockfile, Markdown, TypeScript config.

---
