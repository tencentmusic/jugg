# Installation

## Download

- [Latest stable release](https://github.com/sickworm/jugg/releases/latest)
- [Latest nightly build](https://github.com/sickworm/jugg/releases/download/nightly/jugg-nightly.zip): automatically built from `main` and may contain changes that have not been fully verified

Download the plugin zip, then install it from Android Studio via `Settings` → `Plugins` → `Install Plugin from Disk...` and restart the IDE.
