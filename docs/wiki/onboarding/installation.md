# Installation

## Download

- [Latest stable release](https://github.com/sickworm/jugg/releases/latest)
- [Latest main nightly build](https://github.com/sickworm/jugg/releases/download/nightly-main/jugg-nightly-main.zip): automatically built when `main` has a new commit
- [Latest develop nightly build](https://github.com/sickworm/jugg/releases/download/nightly-develop/jugg-nightly-develop.zip): automatically built when `develop` has a new commit and may contain changes that have not been fully verified

Download the plugin zip, then install it from Android Studio via `Settings` → `Plugins` → `Install Plugin from Disk...` and restart the IDE.
