# Installation

## Download

- [Latest stable release](https://github.com/sickworm/jugg/releases/latest)
- [Latest develop canary build](https://github.com/sickworm/jugg/releases/download/canary-nightly/jugg-canary-nightly.zip): automatically built when `develop` has a new commit and may contain changes that have not been fully verified

Download the plugin zip, then install it from Android Studio via `Settings` → `Plugins` → `Install Plugin from Disk...` and restart the IDE.
