# Agent 或 CLI 执行失败

CLI、MCP 和 UI 自动化通常会返回可以直接修正的参数或环境错误。先按错误文案调整输入；设备、App 或工程未准备好时，先恢复运行环境再重试。

如果仍无法恢复，请 [报告问题](../guide/report-issue.md)。
