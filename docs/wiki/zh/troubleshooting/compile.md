# 编译问题排查

问题排查已经改为按用户可见现象组织。请选择当前最接近的情况：

- 编译出现源码、资源、Manifest 或生成源码错误：查看[编译失败](./compile-failed.md)。
- Jugg 显示成功，但代码、资源或依赖仍是旧结果：查看[改动没有生效](./changes-not-applied.md)。
- 本轮意外进入 Gradle、长时间等待或持续高占用：查看[Jugg 运行缓慢或卡住](./jugg-slow-or-stuck.md)。
