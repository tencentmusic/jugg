# 运行时问题排查

请选择实际看到的结果：

- App 能正常运行，但代码、资源或初始化逻辑仍是旧结果：查看[改动没有生效](./changes-not-applied.md)。
- 编译部署成功后 App 出现 Java 异常或 native crash：查看[部署后 App 崩溃](./runtime-crash.md)。
- App 无法安装或启动：查看[无法安装、启动或进入 Debug](./app-cannot-run.md)。
