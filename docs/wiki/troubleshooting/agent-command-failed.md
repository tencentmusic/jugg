# Agent or CLI command failed

CLI, MCP, and UI automation tools usually return parameter or environment errors that can be corrected directly. First adjust the input according to the error message. If the device, app, or project is not ready, restore the runtime environment before retrying.

If the problem persists, [report the issue](../guide/report-issue.md).
