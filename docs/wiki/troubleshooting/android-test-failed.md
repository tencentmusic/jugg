# Android Test run or test failed

Jugg needs to determine the test module, test APK, test class, and test method from the current androidTest source file. Fix the first parsing error before checking whether instrumentation has started.

If the error message does not provide enough information to resolve the problem, [report the issue](../guide/report-issue.md).
