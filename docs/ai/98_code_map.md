## 5. Common Investigation Hints

- To check whether a capability already exists: read `98_code_map.md`, then search the corresponding directory for the class name.
- To find why compilation fell back: start at `JuggCompilerHelper` -> `preprocessIncrementalCompile`.
- To investigate deployment-failure recovery: start at `JuggDeployerHelper.deploy` -> `DeployStateRecover.recoverDeployState`.
